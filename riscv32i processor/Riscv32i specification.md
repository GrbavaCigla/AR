### RISCV-V Control Word[12..0]
{RegWrite(1b), ImmSrc(3), ALUSrc(1), MemWrite(1), MemRead(1), MemtoReg(2), Branch(1), Jump(1), ALUOp(2)}

### Control Signals

* **`RegWrite` (1 bit)** — Asserts write-enable for the `RegFile` to specify whether the current instruction writes a result back to a destination register.
  * `1`: Write enabled (used for `ADD`, `ADDI`, `LW`, `JAL`, etc.).
  * `0`: Write disabled (used for `SW`, `BEQ`, and other instructions that do not modify registers).

* **`ImmSrc` (3 bits)** — Selects one of the 5 RISC-V immediate field formats (`I`, `S`, `B`, `U`, `J`) within the `ImmGen` module based on how immediate bits are packed in the instruction.

* **`ALUSrc` (1 bit)** — Selector for the second input multiplexer of the `ALU`:
  * `0`: Second register data `rs2data` (used for `R-type` instructions).
  * `1`: Immediate value generated by `ImmGen` (used for `I-type`, `S-type` like `ADDI`, `LW`, `SW`).

* **`MemWrite` (1 bit)** — Asserts write-enable for the `Data Memory`. Value is `1` exclusively for `SW` instructions.

* **`MemRead` (1 bit)** — Asserts read-enable for the `Data Memory`. Value is `1` exclusively for `LW` instructions. Kept separate from `MemWrite` for explicit operation control and future architecture scalability.

* **`MemtoReg` (2 bits)** — Selects which data source is routed back to the `RegFile` via the writeback MUX:
  * `00`: `ALU` output result (standard arithmetic/logic).
  * `01`: Data read from memory (`LW`).
  * `10`: Return address `PC + 4` (link address for `JAL` / `JALR`).

* **`Branch` (1 bit)** — Indicates a conditional branch instruction (`BEQ`, `BNE`, `BLT`, etc.). Combined with `ALU` flags (`Zero`/comparison flags) to determine if `PC` takes the branch target address or continues to `PC + 4`.

* **`Jump` (1 bit)** — Indicates an unconditional jump (`JAL`, `JALR`). Unlike `Branch`, `PC` always updates to the target address without checking any conditions.

* **`ALUOp` (2 bits)** — Provides a high-level classification of the ALU operation from the main Controller to the `ALU Decoder`, which decodes the exact operation alongside `funct3` and `funct7[5]`:
  * `00`: Always `ADD` (used for address calculation in `LW` / `SW`).
  * `01`: Always `SUB` (used for equality comparison in branches).
  * `10`: Operation depends on `funct3` and `funct7[5]` (`R-type` and `I-type` arithmetic).
